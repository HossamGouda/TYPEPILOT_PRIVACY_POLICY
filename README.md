# TypePilot

## Overview

**TypePilot** is a Chrome extension that expands short typed shortcuts into full text snippets. Type a trigger such as `/reply` in any text field on the web and TypePilot replaces it with your saved snippet, optionally filled in with form values, dates, and calculations.

## Features

- **Text Expansion:** Type a trigger like `/thanks` in email, chat, support desks, CRMs, or documents and it expands to your snippet.
- **Form Fields:** Prompt for names, order numbers, or choices with `{formtext:name}` and `{formmenu:status:Open,Closed}`.
- **Dates and Math:** Insert `{date}`, `{date:+3d}`, `{time}`, and calculated values like `{= price * 1.15}`.
- **Conditions and Loops:** Change the output with `{if:...}{else}{endif}` and `{repeat:...}{endrepeat}`.
- **Rich Text:** Bold, links, lists, and alignment for email editors such as Gmail and Outlook on the web.
- **Organization:** Folders, search, built-in templates, and a Learn Center with copyable examples.
- **Import and Export:** Import from JSON, Text Blaze, or TextExpander exports. Export to JSON any time.

## How to Use

1. **Install the Extension:** Add TypePilot to Chrome from the Chrome Web Store.
2. **Create a Snippet:** Open the popup (or press `Ctrl+Shift+Space`), click **New snippet**, and give it a trigger and text.
3. **Type the Trigger:** Type the trigger in any text field on a web page.
4. **Fill In Forms:** If the snippet has form fields, fill them in and TypePilot inserts the finished text.

## Privacy

TypePilot is local-first. Your snippets are stored in your browser, typed text is only checked on your device to detect triggers, and the extension makes no network requests. See the full [Privacy Policy](PRIVACY_POLICY.md).
